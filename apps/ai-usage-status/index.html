Open Source / VS Code Extension

AI Usage Status

Cursor / VS CodeのExplorer ViewとStatus Barに、Codex・Claude・Antigravityの利用可能枠を表示するオープンソース拡張機能です。

GitHubで見る 詳しく見る
01

概要

ローカルのCodexBar CLIが出力するJSONを読み取り、AIサービスごとの利用可能枠をエディター内に見やすく表示します。拡張機能自身はHTTPサーバー、外部API、認証情報へアクセスしません。

対応エディター
  • Cursor
  • Visual Studio Code
対応サービス
  • Codex
  • Claude
  • Antigravity
02

できること

  • Explorerの専用ビューで主要quotaを一覧表示
  • Status Barで残量をコンパクトに確認
  • Providerごとの全window・リセット日時をQuickPickで表示
  • 60秒ごとの自動更新
  • 外部API・認証情報へアクセスしないローカル完結の設計
03

利用方法

Node.js 20以降、CursorまたはVS Code 1.85以降、そしてCodexBar CLIのインストール・設定が必要です。codexbar dashboard --identity redacted を実行できる環境で利用できます。

リポジトリを取得後、npm install、npm run build、npx @vscode/vsce package を順に実行してVSIXを作成し、エディターの「Install from VSIX...」からインストールします。詳しい手順はGitHubリポジトリをご覧ください。
